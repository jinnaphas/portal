# Precise Portal

หน้า Portal กลางขององค์กร สำหรับรวมลิงก์ ระบบงาน เอกสาร และเครื่องมือต่าง ๆ แบ่งเป็น **หมวดหมู่ → หมวดย่อย → ลิงก์** (ซ้อนหมวดย่อยได้ไม่จำกัดชั้น)
ออกแบบโทนสว่าง ใช้สีหลักของ Precise คือ **ส้ม · เขียว · น้ำเงิน**

เป็นเว็บแบบ Static (HTML/CSS/JavaScript ล้วน) ไม่ต้องติดตั้งโปรแกรมหรือฐานข้อมูล

## ความสามารถ

| | |
|---|---|
| 🗂️ **หมวดหมู่หลายชั้น** | หมวดหมู่ → หมวดย่อย → หมวดย่อยของหมวดย่อย … พร้อม Breadcrumb และเมนูด้านข้าง |
| 🔎 **ค้นหาทันที** | กด `/` หรือ `Ctrl + K` ได้ทุกหน้า ค้นได้ทั้งชื่อหมวด ลิงก์ คำอธิบาย ป้ายกำกับ และคำค้นเพิ่มเติม ใช้ลูกศร ↑↓ และ Enter ได้ |
| ⭐ **รายการโปรด** | กดดาวที่ลิงก์ใดก็ได้เพื่อปักหมุดไว้หน้าแรก (บันทึกในเบราว์เซอร์ของแต่ละคน) |
| 🧭 **Transformation Journey** | การ์ดเส้นทาง Industrial → Platform → Ecosystem Capitalism → Agentic AI Organization บนหน้าแรก (ปิดได้) |
| 📱 **รองรับมือถือ** | จัดหน้าใหม่อัตโนมัติ เมนูด้านข้างกลายเป็นแถบเลื่อนแนวนอน |
| 🔗 **ลิงก์แชร์ได้** | ทุกหมวดมี URL ของตัวเอง เช่น `index.html#/people/learning` |

## วิธีเปิดใช้งาน

- **เปิดในเครื่อง:** ดับเบิลคลิก `index.html` ได้เลย
- **เผยแพร่ผ่าน GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → เลือก branch และโฟลเดอร์ `/ (root)`
- หรือนำทั้งโฟลเดอร์ไปวางบน Web Server / SharePoint / Intranet ที่รองรับไฟล์ Static

## วิธีแก้ไขเนื้อหา (ไม่ต้องเขียนโค้ด)

เนื้อหาทั้งหมดอยู่ในไฟล์เดียว: **`data/portal-data.js`**

### เพิ่มหมวดหมู่ใหม่

คัดลอกบล็อกนี้ไปวางใน `window.PORTAL_DATA = [ ... ]` (คั่นแต่ละหมวดด้วยเครื่องหมาย `,`)

```js
{
  id: "finance",                    // ภาษาอังกฤษ ไม่เว้นวรรค ใช้เป็น URL
  title: "การเงินและบัญชี",
  subtitle: "Finance & Accounting",
  description: "งบประมาณ การเบิกจ่าย และรายงานทางการเงิน",
  icon: "wallet",                   // ดูชื่อไอคอนได้ที่ index.html#/_icons
  color: "blue",                    // orange | green | blue
  children: [                       // หมวดย่อย (ไม่มีก็ลบออกได้)
    {
      id: "expense",
      title: "การเบิกจ่าย",
      icon: "clipboard",
      links: [
        { title: "ฟอร์มเบิกค่าใช้จ่าย", description: "Expense Claim", url: "https://...", tag: "ฟอร์ม" }
      ],
      children: [ /* หมวดย่อยชั้นถัดไป ใส่โครงสร้างเดียวกันได้เลย */ ]
    }
  ],
  links: [ /* ลิงก์ที่อยู่ใต้หมวดนี้โดยตรง (ถ้ามี) */ ]
}
```

### ฟิลด์ของลิงก์

| ฟิลด์ | ความหมาย |
|---|---|
| `title` | ชื่อลิงก์ |
| `description` | คำอธิบายสั้น ๆ |
| `url` | `https://...` = เปิดแท็บใหม่ · `#/strategy/vision` = ไปหน้าหมวดใน Portal · `#` = ยังไม่มีลิงก์ |
| `icon` | ชื่อไอคอน หรือ Emoji เช่น `"🚀"` |
| `tag` | ป้ายกำกับ เช่น `"ใหม่"`, `"PDF"`, `"Dashboard"`, `"ฟอร์ม"` หรือหลายป้าย `["ฟอร์ม", "HR"]` |
| `newTab` | ใส่ `false` ถ้าต้องการเปิดในแท็บเดิม |
| `keywords` | คำค้นเพิ่มเติม เช่น `["expense", "เบิกเงิน"]` |

> ป้าย `ใหม่` จะเป็นสีส้ม · `Dashboard` สีน้ำเงิน · `ฟอร์ม` สีเขียว โดยอัตโนมัติ

### ปรับหน้าแรก / โลโก้

อยู่ใน `window.PORTAL_CONFIG` ด้านบนของ `data/portal-data.js`

- `logo` — ใส่ path ไฟล์โลโก้จริง เช่น `"assets/img/precise-logo.png"` (วางไฟล์ไว้ใน `assets/img/`)
- `heroTitle`, `heroAccent`, `tagline` — ข้อความหัวเรื่องหน้าแรก
- `journey` — การ์ดเส้นทางการเปลี่ยนแปลง (ลบทั้งก้อนออกได้ถ้าไม่ต้องการ)
- `footerNote` — ข้อความท้ายหน้า

### ปรับรหัสสีแบรนด์

แก้ที่ส่วน `:root` ด้านบนของ `assets/css/styles.css` — ตัวแปร `--orange`, `--green`, `--blue` (และเฉดอ่อน/เข้มของแต่ละสี)
ค่าปัจจุบันเป็นค่าประมาณ แนะนำให้แทนด้วยรหัสสีจาก CI Guideline ของ Precise

## โครงสร้างไฟล์

```
index.html              โครงหน้าเว็บ
data/portal-data.js     ★ เนื้อหาทั้งหมด (หมวดหมู่ / ลิงก์ / ตั้งค่าหน้าแรก)
assets/css/styles.css   สี ฟอนต์ และการจัดหน้า
assets/js/icons.js      ชุดไอคอน
assets/js/app.js        ระบบนำทาง ค้นหา และรายการโปรด
assets/img/             วางไฟล์โลโก้/รูปภาพ
```

## หมายเหตุ

- ฟอนต์ IBM Plex Sans Thai โหลดจาก Google Fonts — หากเครือข่ายภายในปิดกั้น ระบบจะใช้ฟอนต์ไทยของเครื่องแทนโดยอัตโนมัติ
- รายการโปรดเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน (ไม่ถูกส่งไปที่ใด)
